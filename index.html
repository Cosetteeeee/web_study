03

CSS 层叠示例

以下示例取自 hw1_ai.html（网页设计任务 1(2) 的 AI 辅助版）中欢迎段落 #welcome .welcome-lede 的 letter-spacing：同一元素被三层普通声明依次命中，最终生效的是行内值 0.1em。

  1. 第 1 层 · 外部样式表（hw1_ai.css 经 @import 引入的基础层）：选择器 .welcome-lede，权重 (0,1,0)，letter-spacing: 0.02em。
  2. 第 2 层 · 文档内部样式表（hw1_ai.html 的 style 元素）：选择器 #welcome .welcome-lede，权重 (1,1,0)，先后声明 0.05em 与 0.07em，同权重后写者胜。
  3. 第 3 层 · 行内样式（该段落 style 属性）：letter-spacing: 0.1em，普通行内声明最终生效。

比较顺序：同来源、同重要性、同层的声明先比选择器权重，权重相同再比源顺序；行内普通声明优先于作者样式表中的普通声明，而继承来的值不参与直接竞争。该页刻意不使用 !important 覆盖行内声明；!important 只翻转重要性层级，并非万能解，本项目中仅保留给「减少动态效果」的降级样式。在浏览器开发者工具中选中原页面该段落，可逐条看到被划掉的声明。

实时演示 · 浏览器真实层叠 规则逐字复刻自 hw1_ai（AI 辅助版）

常州，古称延陵、毗陵，别称龙城，坐落在江苏南部、长江三角洲的腹地：北枕长江，南衔太湖，京杭大运河自西向东穿过老城。青果巷沿南市河铺开，素称「江南名士第一巷」；天宁寺的钟声、文亨桥的月色、红梅公园里的文笔塔，把这座城的记忆安放在寻常巷陌之间。这一页，是我为家乡做的数字名片。

当前生效：第 3 层 · 行内 style → 0.1em
计算值：0.1em（启用 JavaScript 可逐层开关三层规则，实时观察层叠结果）

  1. 层1.welcome-lede { letter-spacing: 0.02em; } — 外部基础层（权重 0,1,0）
  2. 层2#welcome .welcome-lede { letter-spacing: 0.05em; } — 内部样式表（先写，被同权重后写覆盖）
  3. 层2#welcome .welcome-lede { letter-spacing: 0.07em; } — 内部样式表（后写，权重 1,1,0）
  4. 层3style="letter-spacing: 0.1em;" — 行内样式（最终生效）
